# Nano_variant


The sript here is to process nanopore generated raw reads for bulk HIV env variant identification. The pipeline incorporates bioinformatics tools to perform basecalling, HIV env gene determination, quality plot, consensus transcript generation, error correction, chimera removal, HIV env variant identification, and env sequence genotyping. The code was tested comphrehensively under Python 3.6.10.

**To install required python packages:**
```
pip install biopython pandas numpy subprocess argparse
```
**The required external software:**
```
conda install -c bioconda nanoplot usearch cutadapt blast seqtk HMMER medaka racon minimap2 samtools
```
```
vsearch (optional): conda install -c bioconda vsearch
```
```
dorado: https://github.com/nanoporetech/dorado
```
If installing the above packages manually, please open Nano_variant.py and setup the absolute path to each software.

**Running the code**

Run ```python Nano_v10.py -h``` to see all available options.

**There are two modes to run the pipeline:**

  **1. perform basecalling using dorado and all later steps**

```
python Nano_v10.py  -o testrun -nanopore_raw_folder ./pod5 -chimera -duplexreads -identity 0.99
```
  **2. start from basecalled fastq file for processing**
```
python Nano_v10.py  -o testrun -nanopore_basecall_folder ./fastq -chimera -duplexreads -identity 0.99
```
 
**The software has the following output folders:**

basecalled: basecalled bam files

BC_split: samples are split by barcode

  **Output folder:** 
  
    basecalling: adapter removed raw transcripts of env, spikein, and plot of spikein error rates
    
    raw_quality_plot: QC of all raw transcripts
    
    env_quality_plot: QC of env transcripts only
    
    consensus: consensus transcripts generated by racon and medaka
    
    HMM: error corrected consensus nucleotide and protein sequences. The 'envs_nt_orf_unique.fasta' and 'envs_aa_unique.fasta' files are the final env nucleotide and protein sequences respectively.
    
    subtype: HIV subtype assignments for each env variant
    
    statistics.txt: summary of transcript numbers during pipeline processing
