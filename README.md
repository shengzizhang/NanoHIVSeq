# NanoHIVSeq


The sript here is to process nanopore generated raw reads for bulk HIV env variant identification. The pipeline incorporates bioinformatics tools to perform basecalling, HIV env gene determination, quality plot, consensus transcript generation, error correction, chimera removal, and HIV env variant identification and genotyping. The code was tested comphrehensively under Python 3.6.10.

**To install required python packages:**
```
pip install biopython pandas numpy subprocess argparse
```
**To install required external software:**
```
conda install -c bioconda nanoplot usearch cutadapt blast seqtk HMMER medaka racon minimap2 samtools
```
usearch has to be <v12.
```

```
```
dorado: https://github.com/nanoporetech/dorado
```
If installing the above packages manually, please open Nano_variant.py and setup the absolute path to each software.

**Running the code**

Run ```python NanoHIVSeq.py -h``` to see all available options.

**There are two modes to run the pipeline:**

  **1. perform basecalling using dorado and all later steps (GPU required)**

```
python NanoHIVSeq.py  -o testrun -nanopore_raw_folder ./pod5 -chimera -duplexreads -identity 0.99
```
  **2. start from basecalled fastq file for processing (faster with GPU support)**
```
python NanoHIVSeq.py  -o testrun -nanopore_basecall_folder ./fastq -chimera -duplexreads -identity 0.99
```
 
**The software creates the following folders:**

basecalled: basecalled bam files

BC_split: samples are split by barcode if available

  **Output folder:** 
  
    basecalling: adapter trimed raw transcripts of env, spikein, and plot of spikein error rate
    
    raw_quality_plot: QC of all raw transcripts
    
    env_quality_plot: QC of env transcripts only
    
    consensus: consensus transcripts generated by racon and medaka
    
    HMM: error corrected consensus nucleotide and protein sequences. The 'envs_nt_orf_unique.fasta' and 'envs_aa_unique.fasta' files are the final env nucleotide and protein sequences respectively.
    
    subtype: HIV subtype assignments for each env variant
    
    statistics.txt: summary of transcript numbers during pipeline processing 
**process non-HIV env dataset**
   To process non-HIV env dataset, it will be optimal to remove non-target region in the input reads. Alternatively, either a HMMprofile or 5' primer can be provided to locate the target region in raw reads before clustering.
 ```
   python NanoHIVSeq_nonHIV.py  -o testrun -nanopore_basecall_folder ./fastq -chimera -duplexreads -identity 0.975
```
**Suggestions:**

Nanopore basecalling models change over time, it is better to check dorado website for newest models, and can be downloaded and specified using the -nanopore_model_folder option

The default primers used for env gene amplication are in our publication, we use a conserved nucleotide region upstream of env start codon to identify positive strand. If this region is not included in the transcripts, please set the '-primer5' option for the correct 5' primer.
